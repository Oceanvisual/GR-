# Пример результата: reg261

Полный цикл анализа по приказу Росимущества от 11.09.2020 № 261 (административный регламент
предоставления земельных участков без торгов, `tests/fixtures/npa/reg261.docx`). Артефакт 9
постановки, T062.

## Как получено

- Локальный сервис (`gr serve`), `LLM_DATA_POLICY=external_allowed`, модель S3–S7 —
  `anthropic/claude-haiku-5.5` (OpenRouter), промпты discover@1.4.0, detail@1.3.0,
  opportunities@1.0.0, допущения — профиль по умолчанию.
- Живой запуск `run_01M5JRHS193QS0567M97J0VJ2H` (экран 2a): 39 вызовов LLM, 418 816 токенов
  на входе и 89 677 на выходе — около $0,7 по ценам `evals/config.toml`, ~2 минуты.
- Экспорт и экраны 2–6 — повторный запуск `run_01M5JRYWTX8ADZ8WKF8REEAQ2E` на тех же
  ответах модели из кэша LLM (0 новых вызовов) после двух исправлений отчёта покрытия, найденных
  на этом примере (см. ниже).
- `export.json` проверен по `/api/v1/schema/analysis-export.json` (jsonschema, Draft 2020-12):
  0 ошибок. CSV — сценарий «Базовый».

## Что в результате

- 18 процессов, 117 операций; процедуры разд. III, контроль (разд. IV), обжалование (разд. V),
  особенности МФЦ (разд. VI).
- Покрытие: 237 из 596 фрагментов в процессах; 14 фрагментов с действиями вне процессов
  (например, п. 2.12 об оставлении запроса без рассмотрения, п. 4.12, п. 6.1).
- 29 инициатив, все — классическая автоматизация; 6 Quick Wins, 23 Not Recommended; одна
  инициатива требует изменения регулирования, 19 — с контролем человека. Для процесса текущего
  контроля — вывод «оптимизация не требуется».
- Портфель (базовый сценарий, допущения по умолчанию): 6 инициатив, 5,16 млн ₽ накопленного
  эффекта за 3 года, 2 291 ч в первый год.

## Ограничения, видимые на примере

- Модель — Haiku: у 49 из 117 операций исполнитель не указан, хотя в тексте он часто назван в
  общем пункте; часть процессов пересекается (принятие решения встречается в процессах 1, 6, 7,
  16). Точность процессов на eval — 0,73 при цели 0,80 (T059); более сильная модель на S3 —
  следующий шаг.
- Объёмы процессов не заданы — работают заглушки профиля, поэтому большинство инициатив с
  отрицательным эффектом и группой Not Recommended. Суммы — модельная оценка, не финансовый
  результат.
- Ранг считается по баллу (FR-065), поэтому первой в таблице стоит инициатива из группы Not
  Recommended с отрицательным эффектом: балл у неё высокий за счёт простоты и низкого риска.

## Исправлено по итогам примера

- S3 пометил весь `body` как «не описывает процессы», и отчёт покрытия молча терял все пробелы.
  Теперь фрагмент, внутри которого есть фрагменты процессов, в «не процессы» не попадает.
- Голые заголовки подразделов («Рассмотрение Заявительных документов») больше не считаются
  непокрытыми действиями: их пункты проверяются по отдельности.
- Фильтр «Процесс» на экране 4 больше не выходит за ширину страницы.
