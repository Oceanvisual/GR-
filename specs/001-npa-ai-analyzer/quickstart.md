# Quickstart & Validation Scenarios: AI-анализ НПА

Руководство по запуску и сценарии, доказывающие, что фича работает end-to-end. Детали API —
в [contracts/api.md](./contracts/api.md), модели — в [data-model.md](./data-model.md).

## Предпосылки

- Локально: `uv`, Python 3.12; для OCR — `brew install tesseract tesseract-lang`. Сервер: Docker
  с Compose v2 (tesseract уже в образе).
- Для анализа нужен OpenAI-совместимый endpoint. Без него работают загрузка и структура
  (сценарии Q1–Q3, Q9).

## Запуск

```bash
# локально
cp .env.example .env            # LLM_DATA_POLICY, LLM_BASE_URL, LLM_MODEL_*; AUTH_ENABLED=false для local
uv sync
uv run gr serve                 # http://localhost:8000

# сервер (AC-10)
cp .env.example .env            # AUTH_USERS: uv run gr hash-password <login>
docker compose up -d --build
curl -fsS http://<host>:${APP_PORT}/healthz    # {"status":"ok"}
```

## Автоматические проверки

```bash
./scripts/check.sh              # ruff, format, mypy strict, pytest (без сети, FakeLLM)
uv run python -m evals.run      # eval на живой LLM (вручную, перед мержем изменений промптов и моделей)
```
