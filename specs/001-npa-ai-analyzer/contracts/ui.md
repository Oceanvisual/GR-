# UI Contract: AI-анализ НПА

Серверный рендеринг (Jinja2 + HTMX), русский язык, без CDN. Каждый экран использует тот же
сервисный слой, что и `/api/v1`. Метки слоя знаний — бейджи `Факт` / `Интерпретация` /
`Гипотеза` / `Допущение`. Статус проверки — бейдж рядом с элементом.

| # | Маршрут | Экран | Основные элементы | FR |
|---|---|---|---|---|
| 1 | `GET /` | Документы | Форма загрузки (тип и лимиты подписаны), список документов со статусом, кнопка «Запустить анализ», статус LLM-политики | FR-001…005, FR-090.1 |
| 2 | `GET /documents/{doc_id}` | Документ | Реквизиты (с цитатами, редактирование), диагностика, дерево структуры (сворачиваемое), просмотр фрагмента, версии анализа | FR-006, FR-010…013 |
| 2a | `GET /analyses/{run_id}` | Статус анализа | Этапы с прогрессом, ошибки с понятным текстом, «Продолжить» / «Отменить», токены и оценка стоимости | FR-091, NFR-011 |
| 3 | `GET /analyses/{run_id}/processes` | Карта процессов | Список процессов, у выбранного — Mermaid-схема и таблица операций (исполнитель, действие, срок, основание), точки решения, отчёт валидации, блок «Не подтверждено», отчёт покрытия, кнопки проверки | FR-020…028, FR-080 |
| 4 | `GET /analyses/{run_id}/initiatives` | Возможности внедрения AI | Таблица «Процесс \| Проблема \| AI-решение \| Экономия \| Риск \| Приоритет» плюс группа и статус допустимости; переключатель сценария; фильтры; итог портфеля; баннеры допущений; экспорт | FR-090.4, FR-092 |
| 5 | `GET /analyses/{run_id}/initiatives/{ini_id}` | Детальный анализ | Процесс и операции с цитатами, проблема, решение, архитектурная идея, альтернативы, тип регулирования и положения к пересмотру, эффект по трём сценариям, использованные допущения, разбивка балла, правило группы, риски, уверенность, проверка | FR-070…072 |
| 6 | `GET /analyses/{run_id}/settings` | Настройки модели | Глобальные допущения, объёмы процессов, время операций, параметры инициатив (3 колонки сценариев, источник, комментарий), веса и пороги приоритизации; пересчёт через HTMX при сохранении | FR-050…057, FR-062 |
| 7 | `GET /analyses/{run_id}/history` | История решений | Лента `ReviewEvent`: кто, когда, что, было → стало, комментарий; фильтры | FR-082 |
| — | `GET /fragments/{doc_id}/{fragment_id}` (HTMX partial) | Просмотр фрагмента | Текст с подсветкой цитаты, путь заголовков, страницы | FR-072 |

**Обязательные тексты**:
- на экранах 4–6 — баннер «Суммы — денежный эквивалент высвобождаемого рабочего времени по
  модельным допущениям. Это не подтверждённый финансовый результат и не сокращение бюджета»;
- при `requires_input` — «Объёмы процессов не заданы: используются заглушки».

**Безопасность рендеринга**: autoescape Jinja включён. Текст документа выводится только как
текст. Mermaid инициализируется с `securityLevel: "strict"`, подписи экранируются генератором.
